## 三、线性表

线性表表示一串有顺序的数据。常见形式包括数组、`vector`、栈和队��。

### 栈

后进先出，像一摞盘子。适合 Undo。

### 队列

先进先出，像排队买票。适合 BFS。

### 优先队列

不是简单按进入顺序取出，而是优先取“优先级最高”的元素。A* 会把估价最小的状态放在前面。

## 四、集合与状态去重

自动求解会遇到大量重复状态。比如玩家绕一圈后又回到原地，如果不去重，程序会无限搜索。

可以把状态编码为字符串：

```cpp
string encodeState(const Player& player,
                   const vector<Position>& boxes) {
    string key = to_string(player.x) + "," + to_string(player.y);
    for (const auto& box : boxes) {
        key += ";" + to_string(box.x) + "," + to_string(box.y);
    }
    return key;
}
```

然后使用：

```cpp
set<string> visited;
if (visited.insert(key).second) {
    // 第一次出现，允许继续搜索
}
```

箱子数组在编码前应排序，否则同一组箱子换了排列顺序可能被误认为不同状态。

## 五、树与图

### 二叉树

每个节点最多有两个子节点。它可以表示“每次有两个选择”的递归过程。虽然推箱子不一定是二叉树，但搜索树的思想很重要。

### 图

图由节点和边组成：

- 节点：一个游戏状态
- 边：执行一次合法操作
- 起点：初始状态
- 终点：所有箱子都在目标点的状态

推箱子自动求解本质上就是在状态图中寻找一条从起点到终点的路径。

## 六、A* 算法

A* 使用：

```text
f(state) = g(state) + h(state)
```

- `g`：已经走过的实际代价
- `h`：从当前状态到目标的估计代价
- `f`：综合优先级

一种简单的估价函数是箱子到目标的曼哈顿距离总和：

```cpp
int heuristic(const State& state) {
    int result = 0;
    for (const auto& box : state.boxes) {
        result += abs(box.x - nearestGoalX);
        result += abs(box.y - nearestGoalY);
    }
    return result;
}
```

这是学习用的启发式。真正稳定的推箱子求解器还需要处理箱子匹配、死角、隧道和玩家可达区域。

## 七、A* 状态结构示例

```cpp
struct State {
    Player player;
    vector<Position> boxes;
    int g;              // 已经花费的步数
    int h;              // 估价
    string path;        // 到达该状态的操作序列
};

struct CompareState {
    bool operator()(const State& a, const State& b) const {
        return a.g + a.h > b.g + b.h;
    }
};
```

使用：

```cpp
priority_queue<State, vector<State>, CompareState> open;
set<string> visited;
```

## 八、自动求解实现顺序

1. 定义完整状态：玩家位置 + 所有箱子位置。
2. 编写状态编码函数。
3. 编写箱子是否全部在目标点的判断。
4. 生成四个方向的后继状态。
5. 用 `set` 或 `unordered_set` 去重。
6. 先用 BFS 求一个能工作的版本。
7. 再换成优先队列和 A*。
8. 加入死角检测，剪掉明显不可能的状态。

## 九、基础数学知识

### 最大公约数

最大公约数可以用欧几里得算法：

```cpp
int gcd(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}
```

它体现了“把大问题变成更小问题”的思想。

### 质数

质数只有 1 和它本身两个因数。判断 `n` 是否为质数时，不必检查到 `n - 1`，只需检查到 `sqrt(n)`。

基础数学训练能帮助你理解取模、范围、复杂度和状态编码。

## 十、重要的工程注意事项

- 箱子位置必须排序后再编码。
- 玩家位置不一定需要记录精确路径，也可以记录玩家可达区域。
- 发现箱子进入非目标角落时，应立即剪枝。
- 搜索状态过多时，要限制内存并统计搜索节点数。
- A* 的估价函数不能随便写；估价过大可能影响最优性。

## 三、基础知识详解

### 1. 一��数组

```cpp
int scores[5] = {10, 20, 30, 40, 50};
```

数组像一排编号为 0、1、2、3、4 的储物柜。每个格子保存同一种类型的数据。

### 2. 二维数组

```cpp
char board[5][8];
```

二维数组像教室座位表。第一个下标表示第几行，第二个下标表示第几列：

```cpp
board[y][x]
```

推箱子地图天然就是二维数组，因为地图既有行又有列。

### 3. 字符串地图

```cpp
vector<string> level = {
    "#####",
    "#.@ #",
    "# $ #",
    "#####"
};
```

每个字符串是一行，每个字符是一个格子。常见符号：

- `#`：墙
- 空格：地面
- `.`：目标点
- `@`：玩家
- `$`：箱子
- `*`：箱子在目标点

### 4. 函数

函数像一个专门工具。例如：

```cpp
bool isWall(int x, int y);
bool tryMove(int dx, int dy);
bool isWin();
```

函数参数是工具需要的材料，返回值是工具加工后的结果。`bool` 返回“成功或失败”最适合移动判断。

### 5. 内存模型的初步理解

数组的元素按顺序存放，`board[y][x]` 表示找到第 `y` 行、第 `x` 列的格子。访问数组时一定要检查下标，否则可能访问不存在的内存位置。

## 四、推箱子移动规则

玩家尝试移动到 `(nextX, nextY)` 时，按下面顺序判断：

1. 目标位置是墙：不能移动。
2. 目标位置是空地或目标点：玩家走过去。
3. 目标位置是箱子：继续检查箱子后面。
4. 箱子后面是墙或另一个箱子：不能推动。
5. 箱子后面是空地或目标点：箱子前进一格，玩家进入箱子原来的位置。

伪代码：

```text
计算玩家前方
如果前方是墙，失败
如果前方不是箱子，玩家移动
如果前方是箱子：
    计算箱子后方
    如果箱子后方不能走，失败
    否则箱子移动，玩家移动
```

## 六、胜利判断

最简单的胜利条件是：每个箱子的坐标都能在目标点列表中找到对应位置。

```cpp
bool isWin() const {
    for (const auto& box : boxes_) {
        bool onGoal = false;
        for (const auto& goal : goals_) {
            if (box.x == goal.x && box.y == goal.y) {
                onGoal = true;
                break;
            }
        }
        if (!onGoal) return false;
    }
    return true;
}
```

这里使用了暴力枚举：逐个箱子检查，逐个目标点比较。地图很小时完全够用，也适合初学者理解。

## 八、常见 Bug 与调试

### Bug 1：地图第一行长度和其他行不同

后果：访问 `map[y][x]` 时可能越界。解决方法是保证每一行长度相同，或者在读取前检查长度。

### Bug 2：箱子可以穿过墙

检查顺序通常写错了。必须先检查箱子后方，而不是只检查玩家前方。

### Bug 3：胜利条件一开始就成立

如果箱子列表为空，循环可能直接结束。应明确规定“没有箱子是否算胜利”，并在代码中处理。

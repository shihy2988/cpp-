# 阶段 1：C++ 基础语法

> 本文只讲 C++ 基础知识，不与任何游戏项目关联。请把它当作独立的语法学习文档。

## 一、学习目标

完成本阶段后，你应该能够：

- 理解程序的执行顺序
- 声明和使用变量
- 区分常见数据类型
- 使用标准输入输出
- 编写条件判断
- 编写 `for`、`while` 和 `do while` 循环
- 理解表达式、运算符和作用域
- 编写简单的数学和文字处理程序

## 二、顺序结构

C++ 默认从上到下执行语句：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 3;
    int b = 5;
    int sum = a + b;
    cout << sum << endl;
    return 0;
}
```

程序依次完成：创建 `a`、创建 `b`、计算 `sum`、输出结果。生活中可以类比为按照菜谱顺序做菜，但这里不依赖任何具体项目。

## 三、变量和常量

变量是可以改变的命名数据：

```cpp
int age = 14;
age = 15;
```

常量创建后不能修改：

```cpp
const double PI = 3.1415926;
```

命名建议：使用有意义的英文名称，例如 `totalScore`，不要使用大量无意义的 `a1`、`a2`。

## 四、常见数据类型

```cpp
int count = 10;          // 整数
double price = 3.5;      // 双精度小数
char grade = 'A';        // 单个字符
bool passed = true;      // 真或假
```

注意：字符使用单引号，字符串使用双引号：

```cpp
char ch = 'A';
string name = "Alice";
```

使用 `string` 需要：

```cpp
#include <string>
```

## 五、运算符

### 算术运算符

```cpp
+  -  *  /  %
```

`%` 是取余，例如 `17 % 5` 的结果是 `2`。

### 比较运算符

```cpp
==  !=  >  <  >=  <=
```

### 逻辑运算符

```cpp
&&  // 并且
||  // 或者
!   // 取反
```

例如：

```cpp
if (age >= 12 && age <= 18) {
    cout << "符合范围" << endl;
}
```

## 六、输入与输出

```cpp
int a;
string name;
cin >> a;
cin >> name;
cout << a << " " << name << endl;
```

`cin >>` 读取以空白分隔的数据。读取整行文字可以使用：

```cpp
getline(cin, name);
```

如果之前使用过 `cin >>`，再使用 `getline` 时要注意输入缓冲区中的换行符问题。

## 七、分支结构

```cpp
if (score >= 90) {
    cout << "A" << endl;
} else if (score >= 60) {
    cout << "B" << endl;
} else {
    cout << "C" << endl;
}
```

`if` 后面的条件结果必须能够转换为真假。多个条件按从上到下的顺序检查。

`switch` 适合判断一个变量的多个固定值：

```cpp
int choice;
cin >> choice;
switch (choice) {
    case 1:
        cout << "选项一" << endl;
        break;
    case 2:
        cout << "选项二" << endl;
        break;
    default:
        cout << "其他选项" << endl;
}
```

`break` 用来结束当前分支，否则可能继续执行后面的分支。

## 八、循环结构

### `for`

```cpp
for (int i = 1; i <= 10; ++i) {
    cout << i << endl;
}
```

三个部分分别是初始化、继续条件和每轮后的更新。

### `while`

```cpp
int x = 1;
while (x <= 10) {
    cout << x << endl;
    ++x;
}
```

如果循环体没有改变条件相关变量，就可能无限循环。

### `do while`

```cpp
int x;
do {
    cin >> x;
} while (x < 0);
```

它会先执行一次循环体，再判断条件。

## 九、作用域

```cpp
int main() {
    int x = 10;
    if (x > 0) {
        int y = 20;
        cout << y << endl;
    }
    // y 在这里不可访问
}
```

变量通常只能在声明它的代码块及其内部使用。

## 二、线性表

线性表中的元素按照一条直线排列。数组和链表是常见实现。

### 数组

访问下标很快，通常是 `O(1)`；中间插入和删除可能需要移动大量元素。

### 链表

每个节点保存数据和下一个节点的位置。插入删除方便，但随机访问较慢。

初学阶段先掌握 `vector`，理解顺序存储，再学习链表节点。

## 三、栈

栈遵循后进先出：最后放入的元素最先取出。生活中的盘子堆就是类似结构。

```cpp
stack<int> s;
s.push(10);
s.push(20);
cout << s.top() << endl; // 20
s.pop();
```

常见用途：

- 括号匹配
- 表达式求值
- DFS
- 撤销操作

## 四、队列

队列遵循先进先出：先进入的元素先离开。

```cpp
queue<int> q;
q.push(10);
q.push(20);
cout << q.front() << endl; // 10
q.pop();
```

常见用途：

- BFS
- 任务排队
- 层序遍历

## 五、优先队列

优先队列每次取出优先级最高的元素：

```cpp
priority_queue<int> pq;
pq.push(3);
pq.push(10);
pq.push(5);
cout << pq.top() << endl; // 10
```

默认是大根堆。需要最小值时可以写：

```cpp
priority_queue<int, vector<int>, greater<int>> minHeap;
```

它是 Dijkstra 和 A* 等算法的重要工具。

## 六、集合与映射

### `set`

`set` 保存有序且不重复的元素：

```cpp
set<int> values;
values.insert(5);
values.insert(5);
cout << values.size() << endl; // 1
```

### `unordered_set`

通过哈希实现，平均查找速度很快，但不保证有序。

### `map`

保存键和值：

```cpp
map<string, int> score;
score["Alice"] = 95;
```

集合常用于去重，映射常用于建立“名称到数据”的对应关系。

## 七、二叉树

二叉树中的每个节点最多有两个孩子：左孩子和右孩子。

```cpp
struct TreeNode {
    int value;
    TreeNode* left;
    TreeNode* right;
};
```

三种基本遍历：

- 前序：根、左、右
- 中序：左、根、右
- 后序：左、右、根

二叉搜索树满足左子树元素较小、右子树元素较大。理想情况下查找较快，但如果树退化成链表，效率会下降。

## 八、图

图由顶点和边组成：

- 顶点表示对象
- 边表示对象之间的关系

邻接表表示：

```cpp
vector<vector<int>> graph(n);
graph[u].push_back(v);
graph[v].push_back(u); // 无向图
```

有向图只添加一个方向。带权图通常保存目标点和边权：

```cpp
vector<vector<pair<int, int>>> graph(n);
```

## 九、图的基本算法

### 连通性

使用 DFS 或 BFS，从一个点出发，检查能访问到哪些点。

### 无权最短路

使用 BFS，距离数组初始为 `-1`，第一次访问某个点时设置距离。

### 带权最短路

边权非负时，可以使用 Dijkstra。它通常结合优先队列，每次处理当前距离最小的节点。

## 十、基础数学：最大公约数

欧几里得算法：

```cpp
int gcd(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}
```

最小公倍数可以利用：

```cpp
long long lcm(long long a, long long b) {
    return a / gcd(a, b) * b;
}
```

先除后乘可以降低中间结果溢出的风险。

## 十一、基础数学：质数

质数大于 1，且只有 1 和它本身两个正因数。

判断质数：

```cpp
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; ++i) {
        if (n % i == 0) return false;
    }
    return true;
}
```

为什么检查到平方根即可？如果 `n = a * b`，那么 `a` 和 `b` 中至少有一个不大于 `sqrt(n)`。

## 十二、基础数学：筛法

当需要判断大量数是否为质数时，可以使用埃氏筛：

```cpp
vector<bool> prime(n + 1, true);
prime[0] = prime[1] = false;
for (int i = 2; i * i <= n; ++i) {
    if (prime[i]) {
        for (int j = i * i; j <= n; j += i) {
            prime[j] = false;
        }
    }
}
```

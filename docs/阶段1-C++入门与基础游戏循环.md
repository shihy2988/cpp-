## 三、基础知识详解

### 1. 顺序结构

程序默认从上到下执行，就像做早餐：先拿杯子，再倒牛奶，最后吃早餐。C++ 代码中的普通语句通常就是顺序执行的。

```cpp
int x = 3;
int y = 4;
int sum = x + y;
cout << sum << endl;
```

执行顺序是：创建 `x`，创建 `y`，计算 `sum`，输出 `sum`。

### 2. 变量和数据类型

变量可以理解为有名字的盒子。`int` 盒子放整数，`char` 盒子放单个字符，`bool` 盒子放真假。

```cpp
int steps = 0;       // 步数
char command = 'w';  // 一次按键
bool running = true; // 游戏是否继续
```

推箱子中，玩家坐标也是变量：

```cpp
int playerX = 3;
int playerY = 4;
```

### 3. 输入输出

```cpp
char command;
cout << "请输入操作：";
cin >> command;
cout << "你输入了：" << command << endl;
```

`cout` 像喇叭，`cin` 像耳朵。`>>` 表示把输入内容送进变量，`<<` 表示把内容送到屏幕。

### 4. 分支结构

```cpp
if (command == 'w') {
    playerY--;
} else if (command == 's') {
    playerY++;
} else {
    cout << "无法识别" << endl;
}
```

这像交通信号灯：条件不同，程序走不同的路。

### 5. 循环结构

游戏不能只处理一次按键，所以需要循环：

```cpp
while (running) {
    // 打印地图
    // 读取按键
    // 更新状态
}
```

`while` 像“只要还没有下课，就继续上课”。`for` 更适合知道次数的重复任务，例如遍历地图的每一行。

### 6. 坐标系统

地图左上角通常是 `(0, 0)`：

- 向右：`x + 1`
- 向左：`x - 1`
- 向下：`y + 1`
- 向上：`y - 1`

记住：数组下标从 0 开始。

## 六、调试方法

遇到“玩家突然跑到奇怪位置”时，不要马上重写代码，先输出：

```cpp
cout << "x=" << playerX << ", y=" << playerY << endl;
```

然后依次检查：输入是否正确、坐标是否更新、边界判断是否执行、地图打印是否使用了正确坐标。

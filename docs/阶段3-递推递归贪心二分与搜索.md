## 二、递推

递推是根据已经知道的结果推导下一个结果。例如斐波那契数列：

```cpp
long long fib(int n) {
    vector<long long> dp(n + 1);
    dp[0] = 0;
    if (n >= 1) dp[1] = 1;
    for (int i = 2; i <= n; ++i) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}
```

递推通常从较小规模向较大规模计算。

## 三、递归

递归是函数调用自己：

```cpp
int factorial(int n) {
    if (n == 0) {
        return 1;
    }
    return n * factorial(n - 1);
}
```

递归必须有：

1. 基础情况，也叫递归出口。
2. 更接近出口的递归调用。

`factorial(4)` 会依次计算 `4 * factorial(3)`、`3 * factorial(2)`，直到 `factorial(0)`。

## 四、递推与递归的区别

- 递推通常使用循环和数组保存结果。
- 递归依靠函数调用和调用栈保存过程。
- 递推一般更节省函数调用开销。
- 递归更容易描述树、分治和回溯问题。

## 五、暴力枚举与回溯

暴力枚举是尝试所有可能方案。例如从 1 到 3 的全排列：

```cpp
void dfs(vector<int>& path, vector<bool>& used) {
    if (path.size() == 3) {
        for (int x : path) cout << x << ' ';
        cout << endl;
        return;
    }

    for (int i = 1; i <= 3; ++i) {
        if (used[i]) continue;
        used[i] = true;
        path.push_back(i);
        dfs(path, used);
        path.pop_back();
        used[i] = false;
    }
}
```

回溯的过程是“选择、递归、撤销选择”。

## 六、贪心算法

贪心算法每一步都选择当前看起来最好的方案。例如找零问题中，优先使用面值最大的硬币。

但贪心不是任何时候都正确。要证明贪心正确，通常需要说明：

- 当前选择不会破坏后续最优解
- 可以把一个最优解转换为包含当前贪心选择的最优解

经典例子：活动选择问题。按结束时间从早到晚选择活动，可以得到最多的不相交活动数量。

## 七、二分查找

二分查找用于有序数据：

```cpp
int binarySearch(const vector<int>& a, int target) {
    int left = 0;
    int right = static_cast<int>(a.size()) - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] == target) return mid;
        if (a[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

每次将搜索范围缩小一半，时间复杂度是 `O(log n)`。

## 八、二分答案

二分答案不一定是在数组中查找，而是在答案范围中查找。它需要一个单调性：当答案从小变大时，判断结果只能从“不满足”变成“满足”，不能来回变化。

一般模板：

```cpp
int left = 0;
int right = 1000000;
while (left < right) {
    int mid = left + (right - left) / 2;
    if (check(mid)) right = mid;
    else left = mid + 1;
}
```

`check(mid)` 表示判断候选答案是否可行。

## 九、DFS

深度优先搜索沿着一条分支尽可能深入，再返回寻找其他分支。它通常使用递归或显式栈。

适合：

- 枚举所有方案
- 连通块统计
- 树的遍历
- 回溯问题

## 十、BFS

广度优先搜索使用队列，一层一层访问节点。无权图中，BFS 第一次到达节点时得到的是最短边数。

```cpp
queue<int> q;
q.push(start);
visited[start] = true;

while (!q.empty()) {
    int u = q.front();
    q.pop();
    for (int v : graph[u]) {
        if (!visited[v]) {
            visited[v] = true;
            q.push(v);
        }
    }
}
```

## 十一、复杂度比较

- 逐个检查：`O(n)`
- 二分查找：`O(log n)`
- 全排列：`O(n!)`
- BFS/DFS：通常是 `O(V + E)`，其中 `V` 是节点数，`E` 是边数

学习算法时，要同时关注“是否正确”和“是否足够快”。

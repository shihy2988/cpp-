# 信息学奥赛入门基础测试卷

## 一、考试信息

- 适用对象：信息学奥赛入门阶段学生
- 建议年级：小学高年级至初中阶段
- 考试时间：120 分钟
- 满分：100 分
- 允许语言：C++17
- 重点考查：C++ 基础语法、模拟、枚举、数组、字符串、基础数学和简单复杂度意识

> 本试卷不涉及复杂数据结构和高级算法，重点考查学生能否把基础知识正确转化为程序。

---

## 二、能力要求

完成本试卷时，学生应具备以下能力：

1. 能看懂变量、表达式、输入输出和基本控制结构。
2. 能正确使用 `if`、`for`、`while`。
3. 能处理一维数组、二维数组和字符串。
4. 能使用模拟和暴力枚举解决小规模问题。
5. 能完成最大值、计数、排序、查找等基础任务。
6. 能判断奇偶数、质数、最大公约数等基础数学问题。
7. 能识别数组越界、死循环、整数除法等常见错误。
8. 能估计简单程序的时间复杂度。

## 21. 奇数和偶数

## 22. 成绩统计

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int x;
    int maximum = -1;
    int minimum = 101;
    int sum = 0;

    for (int i = 0; i < n; ++i) {
        cin >> x;
        if (x > maximum) maximum = x;
        if (x < minimum) minimum = x;
        sum += x;
    }

    cout << maximum << endl;
    cout << minimum << endl;
    cout << sum / n << endl;

    return 0;
}
```

## 23. 反向输出字符串

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;

    for (int i = static_cast<int>(s.size()) - 1; i >= 0; --i) {
        cout << s[i];
    }
    cout << endl;

    return 0;
}
```

## 24. 矩阵元素统计

```cpp
#include <iostream>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    int positive = 0;
    int zero = 0;
    int negative = 0;

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            long long x;
            cin >> x;

            if (x > 0) {
                ++positive;
            } else if (x == 0) {
                ++zero;
            } else {
                ++negative;
            }
        }
    }

    cout << positive << endl;
    cout << zero << endl;
    cout << negative << endl;

    return 0;
}
```

# 第八部分：评分与能力判断

## 90～100 分：基础扎实

- 能熟练使用基本语法
- 能独立完成简单模拟和枚举
- 可以开始学习排序、递归和 BFS

## 75～89 分：基础较好

- 基础语法基本掌握
- 可能在边界条件或细节上出错
- 建议加强数组、字符串和调试训练

## 60～74 分：基础入门

- 能看懂简单程序
- 编程能力还不稳定
- 建议重新练习分支、循环、数组和函数

## 0～59 分：需要补基础

- 变量、循环或数组等概念尚未掌握
- 不建议直接学习高级算法
- 应先完成 C++ 基础语法和简单编程练习
